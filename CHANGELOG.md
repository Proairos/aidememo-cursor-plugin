# Changelog

## 1.1.0 (2026-10-29)

Adds `create_note`: once you turn on Add Notes for Grok Bot in AideMemo, Grok Bot can add a new note with the
text it gives. Add Notes is off until then, and no tool can change or delete an existing memory. The skill says
when to add a note.

## 1.0.0 (2026-10-26)

First release: the AideMemo connector for Grok Bot, with the `aidememo-memories` skill.
